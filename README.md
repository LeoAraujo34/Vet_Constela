# Constela Pet

Site institucional fictício de uma clínica veterinária, desenvolvido como projeto acadêmico e de portfólio.
O projeto simula a presença digital de uma clínica veterinária, apresentando seus serviços, informações institucionais, formas de contato e um formulário para envio de mensagens.

## Sobre o Projeto

O Constela Pet foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em desenvolvimento web, principalmente na construção de páginas utilizando HTML, CSS e PHP.
O projeto possui múltiplas páginas conectadas entre si, mantendo uma identidade visual consistente entre elas.
Além da parte visual, foi implementado um formulário de contato utilizando PHP para receber e validar os dados enviados pelo usuário.

> **Observação:** A Constela Pet é uma clínica fictícia criada exclusivamente para fins acadêmicos e de portfólio.

## Funcionalidades

-  Página inicial com apresentação da clínica
-  Seção de serviços veterinários
-  Página institucional "Sobre"
-  Página de contato
-  Formulário de contato
-  Validação dos campos do formulário
-  Layout responsivo
-  Navegação entre as páginas
-  Links para contato via WhatsApp
-  Footer com informações da clínica
-  Identidade visual própria
-  Elementos adaptados para diferentes tamanhos de tela
